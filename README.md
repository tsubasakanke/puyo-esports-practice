# ぷよぷよ eスポーツ れんしゅう場（非公式）

Switch などの「ぷよぷよeスポーツ」の感覚で、PC のブラウザで練習するためのファンメイドのゲームです。
SEGA とは関係ありません。SEGA の画像・音楽・キャラクターは使っていません（ぷよの絵も効果音もプログラムで作っています）。

## 遊べるもの

- **ひとり練習**（通ルール）
  - 原作と同じアルゴリズムの配ぷよ（シード 0〜65535、128 手でループ）
  - 実測フレームに合わせた操作・連鎖のテンポ
  - 1 手戻す、最初からやり直す、シード・色数（3〜5 色）の変更
- **CPU 対戦**（5 段階の強さ・先取制）
  - おじゃま・相殺・予告ぷよ・マージンタイムあり
- **オンライン対戦**（2〜4 人・先取制）
  - 部屋を作って、招待リンクか 7 文字の部屋コードを友達に送る
  - 同じ PC の 2 つのタブでも試せる
- **設定**：キー割り当て、横移動の長押し開始（DAS）と速さ（ARR）、音量、色のマーク表示

フィーバールールはこれから作ります。

## 操作（初期設定）

| キー | 動作 |
|---|---|
| ← → | 移動 |
| ↓ | 落とす（ソフトドロップ） |
| Z | 左回転 |
| X / ↑ | 右回転 |
| U | 1 手戻す |
| R | 最初からやり直す |
| Esc | ポーズ（シード・色数の変更、タイトルへ） |

## 開発

Node.js 22 以上が必要です。

```bash
npm install
npm run dev
```

ブラウザで表示された URL（例: http://localhost:5173 ）を開きます。

```bash
npm run check
```

型チェック・テスト・本番ビルドをまとめて実行します。

## 仕組み

- `src/engine` … ルール本体。1/60 秒ずつ進む決定的な状態機械（描画・通信に依存しない）
- `src/render` … PixiJS（WebGL）の描画。ぷよのテクスチャ、アニメーション、レイアウト
- `src/ui` … 画面遷移とゲームループ
- 設計書: `docs/superpowers/specs/2026-10-09-puyo-esports-practice-design.md`

数値の出典（Puyo Nexus、ぷよ界隈の実測記事など）は設計書の §12 にまとめています。
